# Rebirth 20 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend rebirths to 20 with the simulated cost curve, move the free 2nd mount slot to Rebirth 6, keep 1 + n//4 creatures, add permanent rebirth luck at 10/20, Lordship titles every 2 rebirths, and an income-priced saddle.

**Architecture:** All tuning lives in `Config.luau` as data and small pure functions (`rebirth`, `rebirthKeep`, `rebirthLuck`, `rebirthTitle`, `Costs.saddle`, `hatchOdds`). Services read those functions; nothing new is saved per player (luck and title are derived from `data.Rebirths`). UI reads the same functions plus player attributes.

**Tech Stack:** Roblox Luau (Studio place "Steal a Mount", placeId 123937616497204), offline tests in `steal-a-ride/tests/run_feedback_checks.py` (real source + stubs, run with the Luau CLI).

**Spec:** `steal-a-ride/docs/superpowers/specs/2026-10-09-rebirth-20-design.md`

- [ ] **Step 3: Implement.** `Config.hatchOdds`:

```lua
-- Exact chance (0..1) of each rarity 1..5 from a normal egg, matching HatchService.roll.
-- luck = roll twice, keep the better; luckyPass (LuckyPassChance) + rebirthUp (Config.rebirthLuck) = one chance to go one rarity up.
-- Shown in the Store before purchase (paid random item odds disclosure).
function Config.hatchOdds(luck: boolean?, luckyPass: boolean?, rebirthUp: number?): { number }
	local total, cum, odds = 0, 0, {}
	for i = 1, 5 do
		total += Config.Rarities[i].odds
	end
	for i = 1, 5 do
		local before = cum
		cum += Config.Rarities[i].odds / total
		odds[i] = if luck then cum ^ 2 - before ^ 2 else cum - before
	end
	local p = (luckyPass and Config.LuckyPassChance or 0) + (rebirthUp or 0)
	if p > 0 then
		for i = 5, 1, -1 do -- descending so odds[i - 1] is still the unshifted value
			odds[i] = odds[i] * (if i == 5 then 1 else 1 - p) + (if i > 1 then odds[i - 1] * p else 0)
		end
	end
	return odds
end
```
